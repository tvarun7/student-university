# Student University demo contract
ESM Node 22+, Express API, Angular standalone client. Root owns server/, root package.json, tests, README. Frontend agent owns client/ ONLY. No real screenshot data/assets committed.

All API paths start /api. fetch credentials same-origin. GET /auth/session returns {user:null|{id,username,name,role,department,semester,child_id},csrfToken}; acquire first even before login. Every POST/PUT/DELETE must send X-CSRF-Token. POST /auth/login {username,password,role} returns session shape (rotated csrf). POST /auth/logout returns {ok:true}; refetch session. POST /auth/password {currentPassword,newPassword}.
Errors {error:string}, 400 validation,401 login,403 permissions,404 missing. All IDs strings UUID.

GET /courses -> array {id,code,name,staff_id,staff_name,semester,components:[{key,label,max}]} filtered by role (admin all; staff assigned; student enrolled; parent child enrolled).
GET /students -> array {id,username,name,department,semester}, admin all, staff only own course enrollments. GET /users admin -> array {id,username,name,role,department,semester,child_id,active}; excludes hashes.
POST /users admin {username,name,password,role:'student'|'staff'|'parent',department,semester,child_id:null|studentId}; PUT /users/:id admin {name,department,semester,child_id,active}; DELETE /users/:id admin deactivates, never erase academic history. Admin role not creatable via public API. Parent link validates student. Staff and students edited with these routes.
POST /courses admin {code,name,staff_id,semester,components:[{key,label,max}]}; PUT /courses/:id admin {staff_id,name,semester}; POST /enrollments admin {student_id,course_id} (idempotent). No public registration.
GET /records?studentId=ID&from=YYYY-MM-DD&to=YYYY-MM-DD -> {student:{id,name,username,department,semester},courses:[{id,code,name,semester,staff_name,components,marks:{componentKey:number|null},attendance:{held,present,percentage:number|null},sessions:[{date,slot,present}]}],attendance:{held,present,percentage:number|null}}. Student and parent cannot choose another student. Staff can only see own courses for students they teach. Admin can view any. StudentId optional only for student/parent. Date filter only attendance.
PUT /marks staff only {student_id,course_id,marks:{componentKey:number|null}}; replace marks for this course, unknown key/max validated, must enrolled and staff assigned. Null means not assessed (not zero).
POST /attendance staff only {student_id,course_id,date:'YYYY-MM-DD',slot:1..12,present:boolean}; upsert unique student/course/date/slot. Must enrolled and staff assigned, no future dates.
GET /feedback -> [{id,course_name,student_name,rating,comment,created_at}], student own, staff own assigned courses, admin all; parent forbidden. POST /feedback student only {course_id,rating:1..5,comment:1..2000}; enrollment required; staff_id captured from course. Feedback identified, NOT anonymous. One per student/course updated on resubmit.
POST /assistant student only {question:string,consent:boolean}; response {mode:'local'|'ai',answer:string}. Default local deterministic academic analysis, NOT AI. External OpenAI only enabled via env OPENAI_API_KEY and AI_ENABLED=true, explicit consent required to send scoped marks/attendance/course names (no name/id/feedback). Model env OPENAI_MODEL. All output text not HTML. No write tool. UI should explain local vs AI and consent checkbox.
GET /notices public -> array {id,title,type,body,date}; seeded generic sample circulars, searchable client-side. GET /timetable -> array {course_name,date,time,room}, filtered by visible courses. Seed sample dates fictional. GET /health -> {ok:true}.

Demo seed CLI creates unique generated passwords saved ONLY demo-credentials.txt ignored by git; usernames admin.demo, staff.demo, student.demo, parent.demo; two students and two staff to test isolation; sample six course schemes from screenshots but fictional names/data. Seed opt-in npm run seed; never automatic on production boot. Shared demo account password env DEMO_PASSWORD can be specified explicitly, otherwise random per account. README must explain credentials file. Default local PGlite embedded PostgreSQL in .data; DATABASE_URL switches to pg PostgreSQL, production requires it.
